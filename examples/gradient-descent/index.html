How Gradient Descent Finds Minima

A simple rule, followed repeatedly, can solve problems that look impossible.

Imagine standing on a hillside in thick fog. You cannot see the valley floor, but you can feel the slope under your feet. If you always take a step downhill, you will eventually reach the bottom. This is the entire idea behind gradient descent.

In practice, the "hill" is a loss function that measures how wrong a model's predictions are. The "valley" is the set of parameters that make the model most accurate. Gradient descent tries to find that valley by repeatedly adjusting parameters in the direction that reduces loss.

The Landscape

To see how this works, consider a simple loss landscape: a parabola. The horizontal axis is a single parameter. The vertical axis is the loss. The minimum sits at the bottom of the curve.

Figure 1. Three paths down the same parabola. The blue path uses a moderate learning rate and converges smoothly. The red path overshoots and diverges. The amber path crawls toward the minimum.

The figure above shows three attempts to find the minimum, starting from the same point on the left. Each attempt uses a different step size, called the learning rate. The learning rate is the only thing that changes, yet the outcomes are completely different.

Step Size Matters

The gradient tells you which direction is downhill, but not how far to step. A step that is too large can overshoot the minimum and climb the opposite slope. A step that is too small takes forever to arrive. The right step size depends on the steepness of the landscape.

Figure 2. Drag the slider to change the learning rate. Watch how the convergence path stretches, overshoots, or shrinks. The default value of 0.3 finds the minimum in a few steps.

On a steep slope, even a moderate step size can overshoot. On a gentle slope, the same step size might barely move. This is why adaptive methods like Adam adjust the step size based on the history of gradients.

The Rule, Repeated

Gradient descent is not clever. It does not plan ahead or remember past attempts. At each step, it looks at the local slope and moves downhill. The hope is that the global minimum is reachable through a sequence of locally downhill steps.

The update rule:

For our parabola, the gradient is simply twice the horizontal distance from the origin. When the learning rate is 0.5, the algorithm jumps directly to the minimum in one step. When it is smaller, the path spirals inward. When it is larger than 1.0, the path explodes outward.

What This Means in Practice

Real loss landscapes are not smooth parabolas. They have ridges, plateaus, and multiple local minima. Gradient descent can get stuck in shallow valleys or oscillate across narrow canyons. Yet the same simple rule, with modest extensions like momentum and adaptive rates, underpins nearly all modern machine learning.

The power of gradient descent is not that it is sophisticated, but that it is robust enough to work in spaces with billions of dimensions where no human could reason about the landscape directly.
